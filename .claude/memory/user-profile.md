**Level.** Senior frontend developer, strong in Vue and React, solid TypeScript, some Node.js.
Backend and AWS are the growth area. The goal is to answer senior **backend** interview questions
with confidence.

**What this repo is.** A pet project, not a product. No real users, no deadline. It exists to be
something an interviewer is impressed by, and to be a study vehicle for the AWS Certified
Developer – Associate exam (DVA-C02). "What would you say about this in an interview" is a valid
reason to build something.

**Aim explanations at** a strong frontend engineer who has not run a server in production.
Comparisons to React, HTTP and TypeScript land well. Never assume ops experience. Flag when an
answer uses an AWS service they may not have studied yet.

**AWS position as of 2026-08.** Studied: IAM, EC2, EBS, ELB/ASG, RDS, Route 53, VPC, S3,
CloudFront, ECS, Elastic Beanstalk. Not yet: CloudFormation, SQS/SNS, CloudWatch/X-Ray, Lambda,
DynamoDB, API Gateway, CI/CD, SAM, CDK, Cognito, Step Functions, STS, KMS/SSM.

That list matters, because the chosen architecture leans on Lambda, DynamoDB, API Gateway, Cognito
and CDK — all still unstudied. Explain them, do not assume them.
